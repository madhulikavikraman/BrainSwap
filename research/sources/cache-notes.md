# Local source cache

Downloaded papers (`*.pdf`) and extracted text (`*.txt`) are optional local reading aids and are excluded from Git. The research notes link to public primary sources so they remain usable without this cache.

The [paper ledger](../findings.md#paper-level-reading-ledger) records the reviewed versions. Each topic review records additional discovery references and reading limits. A file's presence in this cache does not imply that it received a complete review.
